# Decoding the Raw Data

The raw file has to be downloaded and fixed first, see {ref}`06_data`.

1.  Go back into EDR. Still in the panel “Raw Dev” set the “Operation” to “Scan Raw” and select your raw dataset as you named it in {ref}`06_data`.

2. The panel in EDR should show you when the dataset started and when it stopped.

```{image} assets/word_image42.jpg
:width: 466px
```

3. Now select Operation “Decode Raw”. This should produce 9 new files: 4 .aux files (where aux0 is the temperature, aux1 is the voltage, and aux5 is the tilt) and 4 files .g1,.g2,.g3,.h1 that refer to our geophones and hydrophone in the trilobit. You will also get a text-file that you need later.

```{image} assets/word_image43.jpg
:width: 373px
```
