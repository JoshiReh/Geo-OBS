# Displaying the Data

UNIS has a licence for the GeoGiga software in Computer Lab 2, which is commonly used to display and analyse seismic data. Unfortunately, GeoGiga cannot open the files produced by EDR208, because their binary header contains wrong values. We have developed a Python script that repairs the files, see {ref}`08_binary_header`.

In the meantime, you can use the software “SeiSee”, which is installed on the laptop. Sometimes the data does not appear directly in the view panel, or it looks broken. Try experimenting with these parameters:
